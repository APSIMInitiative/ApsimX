# CO2 File Details

## CO2.csv

The CO2.csv file was added at some point in the past but its source is unknown. It will however continue to exist here for those users continuing to use the file.

## NOAA_GlobalCO2.csv

This file is intended to help with future updates to the CO2 file as well provide a file with a known data source.

The data source for this file is the Global Monitoring Laboratory and the global figures are used (see reference at the bottom of this file)

**How to update NOAA_GlobalCO2.csv**

Simply get the csv data for the missing years and add them to the file from the page [here](https://gml.noaa.gov/ccgg/trends/gl_data.html) and submit the updated file in a new pull request for review.

## References
